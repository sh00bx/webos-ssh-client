A terminal that runs on the TV itself. It opens above whatever is already on screen — YouTube, an HDMI input, a game — instead of replacing it. Press Back and the session keeps running in the background; come back and you are in the same shell, with the last screenful of output replayed.

Two tabs at once: a remote host and the TV's own root shell. The panel is translucent, movable and resizable, and the picture keeps playing behind it.

Connecting

Password or key (ed25519, RSA). Host keys are pinned on first connect and the app tells you when one changes. Recent targets come back on the next launch, so the usual case is two clicks from the launcher to a prompt.

The same form starts an SCP file session or a local shell on the TV.

Built for a remote, not for a keyboard

Every control is reachable with the D-pad. The key bar sends what a remote cannot — Esc, Tab, ^C, PgUp/PgDn, arrows — the webOS on-screen keyboard is one button away when no USB keyboard is attached, and every control says what it does if you rest on it.

A USB keyboard works too, including Ctrl and Alt chords.

What is in it

  • A real terminal. xterm.js with a WebGL renderer, scrollback, search, mouse reporting, and correct Esc/Ctrl handling for vim, less and tmux.
  • Files on the same connection. The SCP tab is a second channel on the SSH session you already opened — no second login — with streamed transfers in both directions.
  • A local root shell on the TV, in the same window and the same tabs as the remote ones.
  • Sessions that outlive the window. A background service holds them while the app is hidden, so a long build is still running when you come back.
  • Themes that react to the picture behind them, sampling the screen and tinting the terminal against it. Five fixed themes as well, if you would rather it stayed put.

Good to know

Root is optional. Two features need it — the local shell needs a pty the app's sandbox cannot allocate, and the reactive themes need the display capture API. Both helpers ship inside this package and install themselves on first start through the Homebrew Channel; there is nothing to copy onto the TV by hand. Without root the app still runs and still opens remote SSH sessions.

Keys stay on the TV. A private key you store here is kept on the TV itself. If you also store its passphrase, that passphrase is kept in plaintext beside it — leave it empty to be asked at connect time instead.
