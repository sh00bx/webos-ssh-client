webossh — an SSH client that runs on the TV itself

A terminal panel that opens above whatever is already on screen — YouTube, an HDMI input, a game — instead of replacing it. Hide it with Back and the session keeps running; relaunch and you are back in the same shell, with the last screenful of output replayed.

What you get

  • Real terminal. xterm.js with a WebGL renderer, scrollback, search, mouse reporting, and correct Esc/Ctrl handling for vim, less and tmux.
  • Password and key auth (ed25519, RSA). Host keys are pinned on first connect and the app tells you when one changes.
  • Files on the same connection. The SCP tab is a second channel on the SSH session you already opened — no second login — with streamed transfers in both directions.
  • A local root shell on the TV, in the same window and the same tabs.
  • Built for a remote. Every control is reachable with the D-pad, the key bar sends what a remote cannot (Esc, Tab, ^C, PgUp/PgDn), the on-screen keyboard works when there is no USB keyboard, and the window can be moved, resized and made translucent.
  • Themes that react to the picture behind them, sampling the screen and tinting the terminal against it.

Notes

Needs Homebrew Channel for two of those features: the local shell needs a pty the app's sandbox cannot allocate, and the reactive themes need the display capture API. Both helpers ship inside this package and install themselves on first start — there is nothing to do by hand. Without root the app still runs and still opens remote SSH sessions.

A private key you store here is kept on the TV. If you also store its passphrase, that passphrase is kept in plaintext beside it; leave it empty to be asked at connect time instead.
